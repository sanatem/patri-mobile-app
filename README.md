# 📱 Patrimore Financial App

Una aplicación móvil financiera desarrollada con React Native y Expo, utilizando Supabase como backend.

## 🚀 Requisitos del Sistema

### Versiones Necesarias

- **Node.js**: v18.0.0 o superior
- **npm**: v9.0.0 o superior (o **yarn**: v1.22.0 o superior)
- **Expo CLI**: v6.0.0 o superior

### Para Desarrollo Móvil
- **Expo Go** (para pruebas en dispositivo físico)
- **Android Studio** (para emulador Android)
- **Xcode** (para simulador iOS - solo macOS)

## 📦 Dependencias Principales

### Core Framework
- **React**: `19.0.0`
- **React Native**: `0.79.1`
- **Expo SDK**: `^53.0.0`
